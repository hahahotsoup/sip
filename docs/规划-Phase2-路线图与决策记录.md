## 2. Phase2 主线(2-4 周)

### P0-1:md 追踪(sip track ~/notes)
- 只读 + 旁路版本:不搬用户文件,只读它、记版本(用户改笔记,sip 留旧版)
- embedding 只嵌 HEAD(当前版本),历史只留文本,diff 单独嵌一份(语义搜变更)
- 配合:写作回顾(读的×写的)、个人记忆检索(终局)

### P0-2:watch 网页监控 + 幂等清洗硬化
- watch_targets 表已预置(Phase1 建的),补:sip watch add/remove + 定时(或 --sync 集成)
- **幂等清洗 = 治"网页改版影响"的根本**:让同一网页永远产生同一文本,哈希不再因改版/动态内容漂移
  - 清洗管线固定化、可复现
  - 剥离已知动态区:时间戳正则、数字占位、会话片段
  - 增量对比(diff,现成 DiffPlex)只算不存,作为噪音判定信号:增量全是时间戳/短数字 → 判动态页

### P0-3:遗忘机制(--refresh 保鲜 + cleanup)
- Phase1 只有最小 rm;"能忘的库才配谈存"的完整落地:批量清理过期/失效证据(sip ingest cleanup --stale)

### 表结构(Phase2 迁移)
- 数据起来后:articles 加 source_type/source_key 列 + versions 加 diff_grade/semantic_dist 字段
- 原则不变:没有数据支撑不做大重构;SQLite ALTER TABLE 轻量,sip 已有迁移经验

## 5. 决策记录(已定,执行时不得回退)

| # | 决策 | 理由/来源 |
|---|---|---|
| D1 | **润色级也建版**;连续两次润色才判动态页不建版 | 版本即事实:任何一次真实修改都留痕;防噪仍保住(动态页连续微变才停) |
| D2 | **保鲜看 ObservedAt**(本地记录时间),不是 CapturedAt | 双时态语义:过期与否看"我上次确认到现在";已修+测试 |
| D3 | **语言键用 node 脚本追加**,不靠"找文件尾行" | 已踩坑 2 次;键顺序混乱,脚本化一劳永逸 |
| D4 | **SQLitePCLRaw:core/lib.e_sqlite3 2.1.13 + SQLCipher 全家 2.1.11,维持现状** | NuGet 证实 e_sqlcipher 最高 2.1.11(终版天花板,项目停更 SQLCipher 线);bundle 2.1.13 会拉高 provider 冲突;混版实测 71 绿 |
| D5 | 去重命中(cos≥0.92)非交互自动跳过,不替你删;--force 强存 | 判断归你 |
| D6 | 增量对比只算不存(diff 随算随弃,当噪音判定信号) | 存 diff 数据线性膨胀;diff 可从相邻版本重算 |
| D7 | 反转检测 = 距离 ≥ 反转阈值 且 命中立场词表(双验证,只呈现不下结论) | 近似规则,承认误报可能(见 R2) |
