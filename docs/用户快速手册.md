# 🍲 sip 用户快速手册

> 写给刚拿到 sip 的你。五分钟读完，就能开始用。
> 面向真实用户；Agent/AI 使用者请看仓库内《高级用户手册》。

## 0. sip 是什么（一句话定位）

**本地优先的个人信息库**：收集（RSS）、保存（带版本和来源）、追踪（被改过你永远知道）、筛选（去重）、使用（搜索检索）。数据全在你电脑上，不上传、不云端，拷走 `readwithhotsoup` 文件夹就是迁移。

## 1. sip 能做什么（完整命令 + 界面）

### 1.1 命令行（CLI）——所有能力，完整清单

**订阅管理**
```
sip -l [编号]                    列出订阅源/文章（带编号）
sip -d <URL>                     添加 RSS 源
sip -u <编号>                    更新一个源
sip -r <编号> [--yes]            删除一个源
sip -a <编号> / -una <编号>      归档 / 取消归档
sip --sync [--feed N]            只更新"到期"的源
sip --update-all                 强制更新全部源
sip --schedule <编号> <表达式>    更新计划：30m / 1h / 7d / daily@10:00 / weekly@Mon 08:00 / manual
sip --import-opml <文件>         导入 OPML
sip --export-opml [文件]         导出 OPML
sip --onboarding                 推荐源模板（可编辑 templates.json）
```

**阅读与版本**
```
sip --show <编号>                全屏阅读（W 进完整 TUI，Esc 退出）；--json 输出原文给脚本
sip --versions <编号>            看一篇文章的全部版本
sip --diff <编号> [vA vB]        对比两个版本改了什么（默认最近两版）
sip --export <编号|feed:N|all>   导出 Markdown
sip --fulltext <编号> [--yes]    抓取全文到本地缓存
sip --purge-fulltext [编号]      清空全文缓存
sip --feed-info <编号>           源身份与健康状态
sip --today [--refresh]          今日哈汤：每天一小碗值得读的
sip --like <编号> [--ai [理由]]  标记喜欢（♥ 你 / 🤖 AI）
sip --likes                      列出所有标记
```

**搜索**
```
sip --grep "关键词"               全文搜索（不用 AI，中文可搜，百万级 0.5 秒）
sip --search "关键词" [--feed N]  语义搜索（需先 --init 配 AI）
```

**AI 配置与摘要**
```
sip --init                       首次配置 AI（模型 + API Key；必须真实终端手动跑）
sip --config                     查看/修改 AI 配置
sip --index / --reindex          给文章生成向量 / 换模型后重建
sip --summary <编号>             生成摘要
sip --summary-all                补全所有摘要
```

**报告与系统**
```
sip --insights [--window N d]    阅读报告（需开启遥测）
sip --insights-interval <周期>    设定报告提醒（7d/30d/off）
sip --dedup scan|hide|list|undo   跨源去重
sip --policy list|set|remove      源规则（你确认后自动执行）
sip telemetry status|enable|…     遥测（默认关闭，仅本地）
sip simon status|level <1|2|3>    孟思琳安全守护（默认开启，挡位可调）
sip --help / --version           帮助 / 版本
```

> 全局选项：`--json`（结构化输出给脚本）、`--ignoresafeannouncement`（跳过安全横幅）、`--lang zh-CN|en-US`（语言）。

### 1.2 界面（TUI）——全键盘操作

⚠️ **v2.0.0 起 TUI 不再是默认入口**：不带参数启动（双击 exe / 直接敲 `sip`）现在是开 Web。

| PageUp / PageDown | 翻页 |
| u | 更新当前源 |
| F6 | 更新全部源 |
| a / r | 归档 / 取消归档 |
| x | 删除 |
| s | 更新计划 |
| d | 添加订阅源 |
| i | 查看已隐藏 |

| S | 搜索 |

### 1.3 界面（Web）——浏览器里做同样的事

**最省事的一条：双击 `sip.exe`**（不带参数启动 = 起 Web，浏览器自动打开）。手动起是 `sip --start`，终端会打印一行 `Web UI : http://…`，**用那条链接打开**（无密码模式下链接末尾带一次性 `?t=` 令牌，裸访问 `/` 会被故意拒绝）。想省掉每次复制链接就跑一次 `sip webpass` 设个密码。

- 不想自动开浏览器：`sip --no-open`，或把 `readwithhotsoup/sip_settings.json` 里的 `WebOpenBrowser` 设成 `false`。
- 非交互（脚本/管道）下不带参数启动**不会**起服务：它会打印帮助并以退出码 1 结束 —— 免得把脚本挂在一个前台阻塞的服务器上。

网页里能做的事（与终端能力对齐，**同一批核心函数**，数字不会两边不一致）：

| 页面 | 能做什么 |
|---|---|
| 今日哈汤 | 今日清单 + 「今日变化」（新增 / 被改过 / 可能同文，按需计算） |
| 订阅源 | 更新 / 归档 / 去归档 / 删除 / 设更新计划；OPML 导入导出 |
| 阅读 | 收藏、抓全文（首次要读一遍免责声明）、生成摘要、导出 Markdown、**改稿历史 + 逐行 diff + 看旧版正文**；分栏翻页、字号行距栏宽、阅读位置记忆（与 TUI 共用一个文件）。**单栏也能翻页**（按段落分页，不会把一行字切成两半）；右下角 `⇄` 可在「翻页 / 滚动」之间切换。调字号/行距/栏宽**停在原来那段**，不会被打回第一页；**下次打开自动回到上次读到的地方**（页码/节号记在本浏览器）。栏数按阅读区宽度自动收敛（每栏约 18 字/行）；正文图片不会高过一页 |
| 本地导入 | 拖拽或选择文件上传（txt/md/pdf/epub/mobi/docx）；txt/md/epub/docx/mobi 抽出正文（含图，同样可分栏翻页）；**PDF 按页栅格化阅读**，也可以「用浏览器打开」交给浏览器自带的 PDF 阅读器（能选字/搜索/批注），或点「临时链接」拿一个 10 分钟有效、只对这一份的地址贴到别处打开 |
| 搜索 | 全文（FTS5，中文子串可搜）、语义（需先 `sip --init` 并建索引） |
| 改稿追踪 | 列出被作者改过的文章 → 版本清单 → 选两版逐行对比 |
| 跨源去重 | 扫描 → 簇列表 → 成员并排 + 段落级 diff → **隐藏（可撤销，不删除）** |
| 源规则 | 降频 / 归档 / 保留 / 打标签 / 退订备注；`createdBy` 永远是你 |
| 阅读报告 | 报告 + 定时提醒 + 遥测开关与导出 |
| 设置 | 阅读偏好 / 系统（配置总览，只读）/ 治理（挡位、遥测、向量索引、批量摘要、清理全文缓存） |
| 命令面板 | 顶栏 ⌘ 或 **Ctrl/Cmd+K**：`status`/`list`/`today`/`edits`/`dedup`/`policy`/`simon`/`grep 关键词`/`show 12`…（**只读白名单**，不是任意 CLI 执行器） |

> 🔒 **网页里刻意不能做的四件事**：改配置（直接编辑 `readwithhotsoup/sip_settings.json`）、设 Web 口令（`sip webpass`）、输入 AI Key（`sip --init` / `sip aikey`）、**降低挡位或打开 Agent 门**（`sip simon level N` / `sip --agentok`，需要真实终端 + Web 口令）。网页只显示"现在是什么状态"，不提供手滑入口。
>
> 手机/平板也能开（另一个浏览器 = 另一把钥匙，首次要登录）；界面已做窄屏适配，也可以"添加到主屏幕"当 PWA 用。Windows 上绑局域网地址需要一次管理员 `netsh http add urlacl`，见 README。

## 2. 你应该如何使用 sip

### 2.1 第一次（5 分钟上手）
1. 下载单文件 exe，**双击**（或终端里 `sip`）→ 起 Web，浏览器自动打开；首次会问是否设 Web 密码与绑定地址
2. 在网页里点左下角「＋ 订阅」加几个源，或 `sip -d <你的订阅源 URL>`
3. 等它抓完（首次抓取要把该源的文章全部下回来），或 `sip --update-all`
4. 打开「今日哈汤」读今天的一小碗
5. 想要 AI 能力（语义搜索/摘要）：真实终端跑一次 `sip --init`
6. 想用老的终端界面：`sip tui`

### 2.2 每天（养成习惯）
- 早上：`sip --today` 读今日哈汤
- 搜索感兴趣的内容：`sip --grep "关键词"`

### 2.3 数据在哪
所有数据在 exe 同级的 `readwithhotsoup/` 文件夹（rss.db + JSON + fulltext/）——**拷走它就是迁移**。

## 3. 快速故障排查

| 症状 | 原因 | 处理 |
|---|---|---|
| 中文乱码 | 终端编码不是 UTF-8（Windows GBK） | PowerShell 先执行 `[Console]::OutputEncoding=[Text.Encoding]::UTF8`；或把输出按 UTF-8 解码 |
| 命令被拦：🔒 孟思琳拦截 | simon 挡位 2/3 拦截 CLI 写操作 | `sip simon status` 看挡位；挡位 2 用只读命令或去 TUI 操作；挡位 3 只能 TUI；降挡只能在 TUI 命令栏 |
| 报 NO_INDEX / 尚无向量索引 | 没跑过 `--index` | 先 `sip --init` 再 `--index`；`--grep` 不依赖 AI，可先用 |
| `--init` 报"需真实交互终端" | 脚本/AI 代跑被拒（安全设计） | 你自己在真实终端跑 `sip --init` |
| 添加源报 NETWORK_ERROR | 网络不通 / URL 格式错 / 私网被 SSRF 拦 | 检查 URL；内网源需在 ai_config.json 设 `allowPrivateNet: true` |
| 退出码非 0 | 见说明 | 0 成功 / 1 参数或数据库错误 / 2 网络或服务不可达 / 3 资源未就绪（AI 未配置/找不到） |
| 提示"恢复默认语言文件" | 语言文件缺失自动恢复 | 正常现象；自定义翻译编辑 `readwithhotsoup/languages/` 里的文件 |
| 库打不开/损坏 | 数据库自愈 | 自动重建，原库保留现场（`simon status` 看修复记录） |
